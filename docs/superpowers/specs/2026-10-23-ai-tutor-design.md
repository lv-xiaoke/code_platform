# 随题 AI 助教

用户已确认在练习左侧加入 AI 助教、保留右侧编辑器与终端，并要求每次练习默认最大化。按本次明确的开始执行指令直接实施，不重复请求批准。

## 体验
- 题目、笔记、AI 助教共用左侧标签，代码在桌面端始终可见。手机沿用单栏切换。
- 四个快捷入口：给点提示、解释样例、分析代码、分析报错；报错结果旁有让 AI 分析入口。
- 默认发送题面和当前未保存代码。笔记与最近运行历史可选。分析报错通过运行 ID 在后端取该次代码、输入和结果，避免和当前草稿混淆。
- 提示优先，支持追问完整解法；流式显示、停止、失败重试、复制代码、追加笔记。
- 聊天按题目保存在本地 SQLite settings 命名空间中，不改变已有学习表结构；限制单次内容和保留记录量。

## 后端
独立 ai 包负责 schemas、settings/secret、provider、service 和 routes。DeepSeek 固定官方 HTTPS endpoint，模型可选 deepseek-flash/deepseek-v4-pro；先使用非思考模式获取较快回答。通过标准库读取 SSE，不增加依赖。后台线程接收增量，前端轮询现有本地 API。每题最多一个请求、全局最多两个；请求 ID 幂等，超时和错误保留已有回答。服务重启把未完成回答标记中断。仅用户发送时调用外部服务。

## Key
本地设置填写，Windows DPAPI 加密落盘到 data/ai-key.dpapi；不写 SQLite、日志、前端持久化或备份。非 Windows 可用 DEEPSEEK_API_KEY 环境变量。读取接口只返回配置状态和脱敏尾号。连接测试由用户明确点击触发。错误统一映射为中文，不回传供应商原始响应或 Key。

## 验收
覆盖未配置、密钥加密、上下文隔离、旧运行代码、流式协议、停止/重试/并发/重启、同源校验、聊天持久化和 Markdown 安全。真实 Key 尚未提供，因此不声称完成真实 DeepSeek 付费请求；使用本地协议服务器验证 HTTP/SSE，真实服务待用户填写后通过测试连接验证。
