## 实施取舍

- 在现有工作目录的新 `codex/docker-free-desktop` 分支实现，保留用户要求的根目录启动入口。没有物理 worktree 隔离；所有验收数据使用独立路径，降低误写正式数据的风险。
- 项目明确禁止批量删除，因此保留构建、安装、预览、测试与回退产物，不执行技能中的临时目录清理。代价是额外磁盘占用。
- 恢复预览使用短路径 `rp/<ticket前缀>`，避免嵌套恢复目录与 SHA256 来源文件名触发 Windows 路径长度限制；预览目录保留，增加少量磁盘占用。
- 不提交、推送或改动远程 Release；本轮只交付本地可核验安装包。旧版 Docker 路径继续保留，完整桌面版默认本机执行。
