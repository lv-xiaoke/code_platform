# AI 助教验收 · 2026-10-23

## 使用
刷新 http://127.0.0.1:8000/，点击题目即默认占满窗口。左侧选择 AI 助教，右侧保留代码与交互终端。

首次在“AI 设置”填写自己的 DeepSeek API Key，点击“保存并测试连接”。Windows 下由 DPAPI 加密保存到 data/ai-key.dpapi；macOS 存入系统钥匙串；其他系统保存到仅当前用户可读（0600）的 data/ai-key.local。该文件不会进入学习数据备份，换机器或恢复备份后需重新配置。也支持由后端环境变量 DEEPSEEK_API_KEY 提供。

快捷按钮先填入问题，点击发送才调用服务。运行结果旁的“让 AI 分析本次运行”是直接发送入口，并附带原次提交的代码、输入和结果。默认附带本题题面与当前代码草稿，笔记与最近 3 次运行状态可选。已发送的对话会作为该题后续追问的历史。

支持继续提示、完整解法追问、停止、失败重试、代码复制、追加笔记。聊天在本地 SQLite settings 的独立 ai.chat 命名空间保存，保留最近 50 轮，后续请求附带最近 6 轮完整回答。当前题面、草稿每次发送重新取快照。关闭练习会停止本题当前 AI 回答，并按既有机制保存代码与笔记。

## 边界
- 固定 DeepSeek 官方 HTTPS 接口，拒绝重定向；模型 deepseek-flash / deepseek-v4-pro，可在设置切换。
- 上游流式响应经后端读取，前端约 350ms 轮询；同题一条、全局最多两条回答。
- 每次最多 4096 生成 tokens、回答最多 32000 字符；网络读取超时 15 秒，整体处理目标上限 120 秒。停止后不会再追加回答，等待上游读取返回后释放连接。
- 问题最多 4000 字符，代码最多 65536，笔记最多 16000，当前上下文最多 160000 JSON 字符。
- Markdown 以 React 文本和受控代码高亮渲染；不执行原始 HTML、不加载回复中的图片、不允许可执行链接。
- Key 不写入 SQLite、日志或前端持久化；校验失败不回显 Key。学习数据备份包含聊天，不包含 Key。
- 磁盘保存失败仍释放请求槽，并保留最多 16 题的内存应急回答及复制提示；重启前应先复制。
